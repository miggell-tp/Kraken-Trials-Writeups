# MLUC tr0jans: Kraken Trials

> Weekly CTF challenges and writeups by MLUC tr0jans.

Welcome to the official writeup repository for **MLUC tr0jans: Kraken Trials**, a weekly Capture The Flag (CTF) activity for DMMMSU - Mid La Union Campus CIT students.

Kraken Trials is designed to help students build practical cybersecurity skills through hands-on challenges covering topics such as:

- Web Exploitation
- Digital Forensics
- Cryptography
- OSINT
- Network Analysis
- Steganography
- Miscellaneous

## About the Writeups

Each writeup explains the intended solution path of a challenge, including:

- Challenge overview
- Relevant concepts
- Investigation / approach
- Tools used
- Step-by-step solution
- Flag

The goal is not only to show the answer, but to help participants understand the techniques used to solve the challenge.

## Disclaimer

These writeups are intended for educational purposes and for participants who have completed or attempted the corresponding Kraken Trials challenges.

Do not use the techniques described here against systems without authorization.
